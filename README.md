# Установка сертификатов Минцифры России (НУЦ) для Windows 10/11

Самодостаточный CMD-скрипт для автоматической установки национальных TLS-сертификатов НУЦ Минцифры России — `Russian Trusted Root CA` и `Russian Trusted Sub CA` — по официальной инструкции с портала Госуслуг: <https://www.gosuslugi.ru/landing/crt>.

Сертификаты нужны, чтобы браузеры на Chromium (Chrome, Edge и др.) и Windows-приложения без предупреждений открывали сайты, использующие российские TLS-сертификаты (Госуслуги и другие ресурсы с национальным удостоверяющим центром).

## Что делает скрипт

1. **Скачивает** оба сертификата с официального домена Минцифры `gu-st.ru` через встроенный в Windows 10/11 `curl.exe`:
   - `russian_trusted_root_ca_pem.crt` — корневой сертификат;
   - `russian_trusted_sub_ca_pem.crt` — выпускающий сертификат.
2. **Проверяет подлинность**:
   - убеждается, что скачаны именно сертификаты в формате PEM, а не страницы-заглушки от прокси/антивируса;
   - сверяет хэши SHA-256 файлов с эталонными значениями. При несовпадении установка прерывается.
3. **Устанавливает** сертификаты через `certutil` в соответствии с инструкцией:
   - корневой → хранилище «Доверенные корневые центры сертификации» (`Root`);
   - выпускающий → хранилище «Промежуточные центры сертификации» (`CA`).
4. **Проверяет результат** — сообщает `[OK]` или `[ОШИБКА]` по каждому сертификату.

## Требования

- Windows 10 (1803+) или Windows 11;
- доступ в интернет;
- права администратора — *опционально* (см. ниже).

Никаких внешних зависимостей: используются только встроенные утилиты Windows (`curl.exe`, `certutil`). Политика выполнения PowerShell (`ExecutionPolicy`) на работу скрипта не влияет.

## Использование

| Способ запуска | Область установки |
|---|---|
| Двойной щелчок по `Установка_сертификатов_Минцифры.cmd` | Текущий пользователь (`CurrentUser`) |
| Правой кнопкой → «Запуск от имени администратора` | Весь компьютер (`LocalMachine`, рекомендуется) |

При установке корневого сертификата для текущего пользователя Windows может показать окно с предупреждением безопасности — нажмите **«Да»**.

## Проверка результата

**Через графический интерфейс:**

- `Win+R` → `certlm.msc` (для всего компьютера) или `certmgr.msc` (для текущего пользователя);
- `Russian Trusted Root CA` должен быть в разделе «Доверенные корневые центры сертификации → Сертификаты»;
- `Russian Trusted Sub CA` — в разделе «Промежуточные центры сертификации → Сертификаты».

**Через PowerShell:**

```powershell
Get-ChildItem Cert:\LocalMachine\Root, Cert:\CurrentUser\Root | Where-Object Subject -match "Russian Trusted Root CA"
Get-ChildItem Cert:\LocalMachine\CA, Cert:\CurrentUser\CA | Where-Object Subject -match "Russian Trusted Sub CA"
```

**Практическая проверка:** откройте <https://www.gosuslugi.ru> в браузере — страница должна загрузиться без предупреждения «Подключение не защищено».

После установки перезапустите браузер.

## Особенности

- **Mozilla Firefox** использует собственное хранилище сертификатов — импортируйте сертификаты вручную: Настройки → Приватность и защита → Сертификаты → Просмотр сертификатов → Импортировать.
- **Яндекс Браузер** и **Атом** имеют встроенную поддержку НУЦ Минцифры — установка для них не требуется.
- Если Минцифры перевыпустит сертификат на сервере, контрольная сумма перестанет совпадать и скрипт откажется устанавливать файл — это осознанное поведение для защиты от подмены. В этом случае эталонные хэши в скрипте нужно обновить.

## Безопасность

- Сертификаты загружаются только по HTTPS и только с официального домена `gu-st.ru`;
- перед установкой выполняется проверка формата файла и контрольных сумм SHA-256;
- скрипт не содержит скрытых действий — весь код открыт и прокомментирован;
- временные файлы удаляются после установки.
